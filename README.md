
# Seismoconda

A Reproducible Python Software Ecosystem for Seismology and Distributed Acoustic Sensing

---

## Project Roadmap

### Week 1 - 2: Literature review and ecosystem audit

- [ ] Review Bioconda, Conda-forge, Pixi, and research software reproducibility literature
- [ ] Audit 20 - 30 Python packages used in seismology and DAS
- [ ] Identify specific gaps that existing ecosystems do not address

> Deliverable: Package inventory, related-work matrix, initial research questions

### Weeks 3 - 4: Baseline experiments

- [ ] Create reproducible installation benchmarks
- [ ] Test selected packages on macOS ARM64 and Linux
- [ ] Record dependency failures, installation times, and compatibility issues

> Deliverable: Baseline dataset and experimental protocol

### Week 5 - 8: Build Seismoconda MVP

- [ ] Develop a Python-based package inventory and validated tool
- [ ] Create tested environment templates and lockfiles
- [ ] Implement CI workflows and package recipes only where necessary

> Deliverable: Public MVP, documentation, automated tests

### Week 9 - 10: Scientific workflow evaluation

- [ ] Validate Lady Knox seismic and DAS processing environments
- [ ] Run comparative experiments with baseline approaches
- [ ] Document limitations and conduct reproducibility checks

> Deliverable: Benchmark results, case studies, figures

### Week 11 - 12

- [ ] Write introduction, related work, methodolog, and software design
- [ ] Report actual experimental results and limitations
- [ ] Release an archived software version and seek external feedback

> Deliverable: Complete manuscript draft and research artifact
